みんなの花畑の速さを測る

押すと花畑が開きます。画面に出る 描画 fps・推論 fps・推論時間 を見て、 ここへ戻って（ブラウザの戻る）次を押してください。

  1. ① 今の設定（topdown / 640） いちばん重い組み合わせ
  2. ② 軽くする（movenet / 256） 多人数向き。近づいて見切れると弱い
  3. ③ 中間（topdown / 320） 方式はそのまま、解像度だけ下げる
  4. ④ 最速（1人だけ検出） 採用候補ではなく、この端末の上限を知るための物差し

終わったら ふつうに開く（設定は残りません）。

みんなで花火を調整する

表紙の「始める」の下に 版番号が出ます。v0.2.2 以上なら新しいものです。 それより古ければキャッシュなので、ページを引き下げて更新してください。

  1. ① 今の設定で測る 描画fps・推論fps・推論時間が左下に出ます
  2. ② 推論を毎秒3回まで GPU に空きを作る。骨格の追従が少し遅れます
  3. ③ 毎秒2回まで 映像はさらになめらかに。手を振る反応は鈍くなります
  4. ④ 毎秒1回まで 上限を知るための物差し。実用にはしません

描画 fps が映像のなめらかさです。20 を超えれば実用になります。 ふつうに開く
