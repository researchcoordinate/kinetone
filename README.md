# kinetone フェーズ1「おさんぽ足踏み」

高齢者（自立〜軽度要介護層）向けの **その場足踏み（stepping in place）リハビリゲーム** です。
Web カメラ 1 台とブラウザだけで動き、介護施設・サ高住での日常利用と、展示会（CareTEX）でのデモを想定しています。

---

## コンセプト

**1. AI ペットが実況・応援する**
ペットの「ぽて」が足踏みのテンポを刻み、動きに合わせてリアルタイムに声をかけます。
声かけは 2 つのモードを使い分けます。

- **応援モード（情緒）** … 「その調子です」「あと 30 秒です」。短くテンポよく、急かさない。
- **分析モード（客観）** … 「ひざがしっかり上がっていますね」「少しリズムが乱れてきたかな、深呼吸しましょう」。
  指導や指摘の口調にはせず、あくまで“気づき”として伝えます。

安全に関わる声かけ（速すぎ・ふらつき・立ち位置）は他の発話に**割り込んで**最優先で流れます。

**2. 遊びながら動作分析ができる**
足踏み動作そのものが歩行機能の計測になります。歩数・テンポだけでなく、
ひざの上がり・左右差・リズムの安定性まで測り、セッション後にその場でレポートを表示します。

**3. 映像は速度可変で前進する**
背景の散歩映像（ヨーロッパの石畳）は、足踏みのテンポに応じて**再生速度が変わります**。
足を止めれば道も止まり、テンポよく踏めば景色が進みます。

**4. プライバシーはローカル処理**
カメラ映像の処理はすべて端末内で完結し、**映像は外部に一切送信も保存もしません**。
バックエンドはありません。セッション記録も端末のブラウザ（localStorage）にのみ保存されます。

## 起動方法

```bash
npm install
npm run setup:mediapipe   # 姿勢推定のランタイムとモデルをローカルに配置（初回のみ）
npm run dev
```

ブラウザで http://localhost:5173 を開き、カメラの使用を許可してください。

| コマンド | 内容 |
|---|---|
| `npm run dev` | 開発サーバ（LAN 公開あり。別端末からも開けます） |
| `npm run build` | 本番ビルド |
| `npm run preview` | ビルド結果の確認 |
| `npm run test` | 動作分析まわりの単体テスト |
| `npm run setup:mediapipe` | WASM とモデルを `public/mediapipe/` に配置 |

### 展示会・施設で使うときのメモ

- `npm run setup:mediapipe` を済ませておくと、**会場の回線が無くても動きます**
  （未実行の場合のみ CDN にフォールバックします）。
- カメラは `getUserMedia` を使うため、`localhost` 以外で配信する場合は **HTTPS が必要**です。
- 来場者が入れ替わったら、レポート画面の「おわり（次の方へ）」でホームに戻ります。
  ホームに戻るとカメラは停止し、次の方は素の状態から始められます。
- 音量・発話頻度・テンポ音・検出感度は、ホーム画面の「設定」からその場で調整できます。

## デプロイ（Firebase Hosting）

kinetone 専用の Firebase プロジェクトを作って配信します（みまもり時計とは別プロジェクト・同じアカウントで可）。
カメラに必須の HTTPS は自動で付きます。

### 初回だけ（プロジェクト作成と紐付け）

```bash
npx firebase-tools login                                                   # 対話ログイン
npx firebase-tools projects:create kinetone-stepping --display-name "kinetone stepping"
npx firebase-tools use kinetone-stepping
```

- プロジェクトID `kinetone-stepping` は世界で一意です。取られていれば別名にしてください。
  既定の URL は `https://<プロジェクトID>.web.app` になります。
- `firebase use` の実行で `.firebaserc` に既定プロジェクトが書き込まれます。
- 初回デプロイで「Hosting サイトが無い」と言われたら
  `npx firebase-tools hosting:sites:create <プロジェクトID>` を実行してから再度デプロイしてください。

### 毎回のデプロイ

```bash
npm run deploy
```

`firebase.json` の predeploy で **`setup:mediapipe` → `build` を自動実行**してから配信するため、
モデル/WASM の取得忘れは起きません。

### 帯域について（重要）

初回ロードで **姿勢推定モデル＋WASM＋動画で約 20MB** ダウンロードします。
無料の Spark プランは転送 360MB/日（≒ 新規ロード約 18 回/日）です。

- **ブースの 1 台（キオスク）で運用** → 一度読めばキャッシュされるので無料枠で問題なし
- **URL を配って各自のスマホで試す** → 新規端末が増えると 18 回/日で頭打ち。
  広く配るなら Blaze（従量・実費わずか）への切り替えを推奨

大きな静的アセット（`*.wasm` `*.task` `*.mp4` とハッシュ付き JS/CSS）には
`Cache-Control: immutable` を付けているので、キオスクと再訪問は転送を消費しません。

## 画面の流れ

```
ホーム → キャリブレーション → 足踏みゲーム → レポート → ホーム
```

- **ホーム** … 姿勢（立位／着席）と長さを選んで「はじめる」だけ。
- **キャリブレーション** … 全身が映っているかを判定し、映っていなければペットが案内します。
  足型の立ち位置ガイドを表示し、良い状態が 1.6 秒続くと自動で次に進みます。
- **ゲーム** … 背景映像が足踏みに合わせて進みます。歩数・テンポ・残り時間を特大表示。
- **レポート** … 主要 5 指標＋前回比較＋推移グラフ。JSON エクスポート可。

### 着席モード

椅子に座ったまま／椅子につかまりながらでも遊べます。
座位では大腿がほぼ水平になり膝が動かないため、**着目する関節を膝から足首に切り替え**、
しきい値も座位向けに下げています（`SEATED_CONFIG`）。

## モジュール構成

| モジュール | 役割 |
|---|---|
| `src/poseEngine/` | カメラ起動・MediaPipe 推論・landmarks の供給・骨格オーバーレイ。ゲームに依存しない共通部 |
| `src/motionAnalysis/` | landmarks から足踏み指標を算出。**描画・音声・DOM に一切依存しない**ため単体テスト可能 |
| `src/pet/` | AI ペットの状態管理・発話（応援／分析の 2 モード）・発話キュー・メトロノーム・表情 |
| `src/game/` | 足踏みゲームのロジックと画面。背景映像の速度制御を含む |
| `src/report/` | セッション結果レポート、履歴の保存と書き出し |
| `src/ui/` | 共通 UI（大きなボタン、ホーム、キャリブレーション、設定） |
| `src/app/` | アプリ設定（音量・感度など）の型と保存 |

### 設計上の要点

- **カメラと推論ループはアプリ全体で 1 つ**（`PoseProvider`）。画面遷移のたびにモデルを読み直すと
  数秒待たされるため、各画面は「カメラの見せ方（全画面／小窓／非表示）」だけを宣言します。
- **landmarks は React の state に流さない**。30〜60fps で届くため購読コールバックで配り、
  画面表示は 10Hz 程度に間引いています。
- **動作分析はゲーム描画から完全に分離**。合成データを流し込むだけでテストできます
  （`src/motionAnalysis/__tests__/synthetic.ts`）。
- **フェーズ2（立ち座り）への再利用**を想定し、`poseEngine` / `pet` / `ui` はゲーム非依存にしてあります。

## 動作分析の指標

すべて **体幹長（肩の中点〜腰の中点の距離）で正規化**しています。
カメラからの距離や体格が変わっても比較できるようにするためです。

### 歩数カウント

腰から膝（座位は足首）までの縦距離を体幹長で割った値 `drop` を追い、
その「ゆっくり追従する最大値」を立位基準 `baseline` とみなします。

```
持ち上げ量 raise = baseline - drop
```

`raise` がしきい値を上下するヒステリシス（上がり 0.10 / 下がり 0.05）で 1 歩を数えます。
歩数は**上がりのしきい値を跨いだ瞬間**に加算します（利用者が「踏み出した」と感じる瞬間に
反応させるため）。次の 1 歩は下がりしきい値を下回ってからでないと数えないので、
「上昇 → 下降で 1 歩」という定義自体は満たしています。
持ち上げ量のピーク値だけは脚が下りきった時点で確定させます。

### ケイデンス（歩/分）

直近 6 歩の間隔から算出します（外れ値に強い刈り込み平均）。
最後の 1 歩からの経過時間で頭打ちにしているため、足を止めるとなめらかに 0 へ落ちます。
この値が背景映像の速度制御にもそのまま使われます。

### ひざの上がり（体幹長比）

1 歩ごとの `raise` のピーク値の平均です。レポートでは % 表示します。
低下は「すり足傾向」の指標になります。座位では足首基準になるため期待値が変わります。

### 左右対称性（%）

左右それぞれの平均ピーク持ち上げ量を比べます。

```
左右差(%) = |左 - 右| / ((左 + 右) / 2) × 100
```

各側 2 歩以上でのみ算出します（それ未満は「判定できません」と表示）。

### リズムの安定性（変動係数 CV, %）

ステップ間隔のばらつきを平均で割った値です。小さいほど一定のテンポで歩けています。
4 間隔以上でのみ算出します。

### そのほか

- **体幹の横ゆれ（swayIndex）** … 腰の中点に対する肩の中点の横ずれの標準偏差（2 秒窓）。
  一定以上でペットが「無理をせず、つかまってくださいね」と声をかけます。
- **トラッキング品質** … 姿勢を読み取れたフレームの割合。低い場合はレポートに注記が出ます。

> **評価しきい値（とても良い／ふつう／気をつけたい）はプロトタイプ段階の目安値です。**
> 臨床的な基準値ではありません。現場データが集まり次第差し替えられるよう、
> `src/motionAnalysis/summary.ts` の 1 箇所にまとめてあります。

## 背景映像の速度制御

`assets/walking_street.mp4` を全画面（`object-fit: cover`）で敷き、再生速度を動的に変えています。

```
再生速度 = ケイデンス / 基準テンポ   （0 〜 1.7 でクランプ）
```

- 足踏みしていない → `pause()`（`playbackRate = 0` は環境によって例外になるため）
- 基準テンポで足踏み → 等速（1.0）付近
- テンポが 100 歩/分を超えたら、超えたぶんに比例して追加加速（上限 3.0 倍）

速度は時定数 550ms の指数移動平均でなめらかに補間するため、急に変わりません。

**基準テンポ**は「目標テンポ」と「映像本来のテンポ」の相乗平均です。
目標テンポをそのまま等速にすると、ゆっくり設定のときに景色が不自然に遅くなるためです。

ループの継ぎ目は、映像の終端と先端で短く暗転させて目立たなくしています。
映像が読み込めない環境では、無地グラデーションの道の背景に自動で切り替わります。

コース（背景映像）は `src/game/courses.ts` に定義されており、将来増やせる構造です。
フェーズ1 では `walking_street.mp4` の 1 コースのみです。

## AI ペットの実装

- 発話は `queue.push({ text, priority, tag })` に統一。内部では Web Speech API の
  `SpeechSynthesis`（日本語音声）を使いますが、**`SpeechEngine` インターフェースを実装するだけで
  収録ボイスに差し替えられます**（`src/pet/speech.ts`）。
- 発話が重ならないようキューで 1 本ずつ流し、**安全に関わる声かけは割り込み**ます。
  同じ `tag` の待機中の発話は新しいもので置き換えるため、古い情報を喋りません。
- セリフは `src/pet/phrases.ts` に設定として外出ししてあり、後から増やせます。
- テンポの拍そのものは Web Audio の短い音で正確に刻みます（音声合成では拍がずれるため）。
  「イチ、ニ、イチ、ニ」という声かけは数小節に一度まとめて重ねます。
- 表情は「喜ぶ・励ます・心配する・待つ」の 4 状態を持ち、音声と同期します。

セッション結果は `SessionSummary` 型（`schemaVersion: 1`）で保存・書き出しされます。

  "schemaVersion": 1,
  "sessionId": "20260722100000-a1b2c",

  "endedAt": "2026-07-22T10:02:00.000Z",
  "durationSec": 120,
  "posture": "standing",
  "difficulty": "normal",
  "targetCadence": 90,
